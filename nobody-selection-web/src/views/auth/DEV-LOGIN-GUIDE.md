# 开发模式登录说明

开发环境下可跳过短信验证码，快速体验各角色界面。

## 快速登录账号

| 角色 | 手机号 |
|------|--------|
| 学生 | 13800000001 |
| 家长 | 13800000002 |
| 教师 | 13800000003 |
| 管理员 | 13800000004 |

访问 http://localhost:5173/auth ，选择角色即可进入对应首页。退出登录后可切换角色。

后端未启动时，前端使用本地模拟数据；后端可用时，也可调用 `POST /api/auth/dev-login`。

仅用于本地开发与演示，请勿用于生产环境。
